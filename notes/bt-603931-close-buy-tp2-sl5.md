# 追加：新卖点规则（止盈优先，2% 与 -5% 均以昨收为基准）

## 规则定义

每个交易日按下面顺序判断，**止盈优先于止损**：

1. 开盘价相对**昨日收盘价**涨幅 ≥2% → 按开盘价卖出
2. 当日最高价相对**昨日收盘价**涨幅 ≥2% → 按「昨收×1.02」卖出
3. 当日最低价相对**昨日收盘价**跌幅 ≤-5% → 按「昨收×0.95」卖出
4. 都没触发 → 继续持有，第二天按新的昨收重算这三条

买入价 = 买入日收盘价。持仓跨天时，基准每天随昨收滚动更新（这是「按昨日收盘价算」的字面实现，也是逐日盯盘的实际做法）。

## 4. 为什么所有档位都到不了 1：结构性原因

止盈只有 1%，止损却是 -5% 到 -10%，这是一个赔率 1:5 到 1:10 的结构：

- 止损 -7%，赔率 1:7，正期望需要胜率 > 87.5%，实测 80.2% → 负。
- 止损 -4%，赔率 1:4，需要胜率 > 80%，实测 72.9% → 负。
- 止损 -2%，赔率 1:2，需要胜率 > 66.7%，实测 50.0% → 负。

**这不是调参数能解决的，是「小止盈 + 大止损」这个结构本身在数学上就要求一个它达不到的胜率。**
越放宽止损，胜率往上爬、但每笔亏的幅度也变大，两条线始终没交叉。净值从 -2% 的 0.53 一路爬
到 -10% 的 0.99，就是在逼近这个平衡点但没跨过去。

## 7. 结论

1. 上一版「-3% 最优、净值 1.19」的结论**作废**，它完全是「止盈优先」这个错误口径撑起来的。
2. 逐笔真实定序后，**-2% 到 -10% 的全部档位净值都低于 1**，没有一个能赚钱。
3. 表现最好的是 -10%（0.9889）和 -7%（0.9783），两者都只是「少亏」，不是「赚钱」。
4. 想盈利只有两条路：换掉「小止盈+大止损」的结构，或者放弃在这只票上做日内反弹。
   单看数据，唯一站到 1 上方的是「无止损 + 只持一天 + 止盈 1%」，净值 1.0581，但它
   建立在标的跌 50% 的背景下，且利润来源是高频小赚堆积，脆弱性很高。
