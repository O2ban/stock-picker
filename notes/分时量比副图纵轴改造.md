# 分时量比副图纵轴改造（2026-10-20）

## 目标
分时（period='min'）量比副图：左侧只显示当日量比最大/最小值，取消等距刻度线与等距刻度数字，保留 1.0 / 3.0 两条参照线且不带数字；右侧无刻度值；时间标签移出坐标区；端点数字改 DOM 覆盖层自绘在面板内侧。

## 落地要点（public/chart.js）
- `timelineRatioAxis`：按当日真实极值 lo/hi 算，下界锁 0；`slack = span*0.35` 决定是否把轴兜到 1.0 / 3.0；`interval = max-min`（整跨度），使 ECharts 只在两端出刻度；返回值额外带 `hi`/`lo`（真实极值，供覆盖层标数字用，不能读轴端）。
- 量比轴 `splitLine: { show: false }`；`axisLabel: { show: false }`（成交量轴同）；价格轴保持原样（inside 标签 + formatter）。
- markLine 保留 `{yAxis:1}`、`{yAxis:3}` 两条，`label:{show:false}`，3.0 线单独 #8a7a44。
- 时间标签：`bottomPad=17`，`layoutDateLabels` 把 09:30 / 15:00 放到网格下沿外。
- `layoutRatioLabels(slot)`：两个 span（`.chart-ratio-label`），`convertToPixel({yAxisIndex:2}, hiV/loV)` 定位，夹在 `rect.y+1` ~ `rect.y+rect.height-12`；
  重叠时按 12px 行高避让 —— **写回 style 必须用避让后的 hiTop/loTop**（踩过坑：写回 clampY 原值导致避让失效）。
- 盘中 tick 扩轴（yPatch[2]）后：`slot.ratioAxis` 要带 `hi`/`lo` 一起存，再调 `layoutRatioLabels(slot)`；非分时周期清空文本。

- 画布层量比区文本为空（`canvasRatioTexts: []`）→ 无等距刻度数字、右侧无数字。
- `overlapLegend: false`，标签在 grid2 内（`botInside: true`）。
- 切回 day 周期 `leftover: []`，无残留。
- 截图确认：仅 2.92（顶）/0.56（底）、两条虚线（灰=1.0、黄=3.0）、09:30 / 15:00 在图外来。
