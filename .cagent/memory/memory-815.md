每天15:20自动保存当天清单里每只票的每分钟走势到本地，16:40与21:00各结算一次盈亏（重复跑不会算错，是为防单次失败）。限制：只存当天被选中的票，全市场每分钟数据一天几十G，机器只剩5.3G空间撑不住；这类分时数据源头只能倒查5个交易日，漏一天就永久丢了。同理，任何长周期策略验证都依赖这套归档持续运行，缺归档则样本永久缺失。
