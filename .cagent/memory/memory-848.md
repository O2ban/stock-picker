用户要求「点股票进看盘，体验和选股页完全一致」。与其在复盘页再画一套图表，直接把行点击接到同一个看盘抽屉上，一处改造同时解决体验一致、避免两套图表各说各话、避免维护两份逻辑三个问题。旧复盘脚本的统计与格式化实现应逐字复刻进新脚本，但数据页签内容由独立脚本渲染，不再依赖旧复盘脚本，防止互相牵连。改造前需先检查旧复盘脚本被引用的位置，避免删除后出现空引用。
