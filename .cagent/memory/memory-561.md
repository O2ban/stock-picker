两类读数恢复问题：(1) 日K/周K点一下锁十字线后顶部行情信息条（当前价/涨跌幅/最高/最低/开盘/量比/振幅/成交量/成交额）会切成所指那天/那周——这本身正确；但取消十字线时只刷新了下方指标行、漏了顶部条，导致顶部停在历史某天像行情卡死。修法是把『取消十字线』做成两件事一起做：下方指标回最新 + 顶部行情条回最新，分时那边也补一次刷新保证两种图行为一致。(2) 分时成交量格原先显示全天累计成交量，与旁边价格的瞬时口径不一致；应改为显示最后一根成交量柱（最近一分钟量），十字线锁在某分钟时显示那一分钟柱子，取消后回最后一根，二者口径统一。验证方式：无头浏览器按手机尺寸走『点一下锁定→再点一下取消』的完整对照，逐字比对取消前后数字一致。
