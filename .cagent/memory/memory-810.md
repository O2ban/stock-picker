用户质疑「昨收条件」是否基于已有策略时，应正面承认：原策略里「昨日」这一项是关着的，根本没有「昨天必须收涨」这条。该条件是事后在仅125条小样本上添加出来的（当时号称胜率87%），但用289万条全市场数据验证后，昨日收阳与收阴差距仅0.08个百分点且收阳胜率更低，11-19的158笔实盘又一次否定它。现它只作为页面上参考的一个分数、做成开关可调但默认不参与选票。教训：凡是事后在小样本上「看着很漂亮」的条件，必须经大样本复核后才可写进策略，否则会在用户现场核对时暴露为无依据的加戏。
