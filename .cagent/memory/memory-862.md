通达信官方口径（来自量化平台文档）：1分钟K线覆盖仅2024年9月至今，5m/15m/30m/1h覆盖2017年1月至今。其他通达信渠道的限制：PC客户端盘后下载（.lc1落本地）取决于客户端里下过多少，盘中不能下只能盘后下，默认只缓存看过的股票；官方'个人行情数据'下载页只提供hsjday.zip（沪深京日线完整包），没有分钟历史包；在线行情协议（pytdx等）get_security_bars单次最多800根，只能翻最近窗口拿不到多年前。结论：通达信.lc1格式对、口径对（含真OHLC），但官方拿不到多年历史分钟，想要1999年至今的lc1只能买金数源这类第三方打包。
