分时量比开盘值明显小于通达信、越往后越接近，根因不是数据源也不是总槽数 242/240，而是计算「已开盘时间占比」时把开盘第一分钟（9:31 那个点）算成了已走 2 分钟，分母翻倍使开盘段数值被压掉一半多。改成按真实已开市分钟数计算、以 240 分钟为全天框架后，实测三只票开盘第二分钟与通达信完全对上（云铝 2.7→5.39、茅台 6.87、宁德 11.10），形态也从低平变成「开盘高尖峰后一路下行」。量比公式本身：累计成交量 ÷（5 日均量 × 已开市时间占比）。
