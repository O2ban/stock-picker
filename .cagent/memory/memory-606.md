在测试“大盘连跌+站上20日均线+5日均线向上”的组合时，发现“5日均线向上”这一条件显著降低了平均收益（从+0.208%降至+0.164%）并大幅减少出手次数。原因是大盘已连跌数日，此时5日线仍向上的股票属于逆势股，它们往往没有深跌（触发不了中间价入场），一旦触发往往是补跌开始。相反，“站上20日均线”是有效的正向过滤，能将平均收益从0.15%提升到0.21%。这提示在弱势市场中，顺势的“抗跌”指标可能误导入场时机。
