stock-picker 实测：指定 11/17、11/13 均为 0 条，原因是数据源（免费分时接口）只保留最新一个交易日的分钟流水，按历史日期请求仍返回最新日数据，日期对不上全被筛掉。因此“基准日只能选最新交易日”是数据源限制而非策略失效。应处理为：所选日期不是最新交易日时明确提示无分时数据并列出可用日期，避免用户误判策略选不出股票。
