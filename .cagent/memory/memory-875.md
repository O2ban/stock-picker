分时浮层按日期标注买卖点时踩过两个坑：(1) renderSubminDate 只取 tradesFor()[0] 加买入优先，导致某天既是前一笔卖出日(T1)又是后一笔买入日(T)时红点或绿点被顶掉（51个买入日里50个走错），正确做法是用 drawSubminDay 把当天全部相关记录合进同一次绘制——买入日绿点落15:00收盘那根、卖出日红点落实际卖出时刻那根、被过滤的画灰色虚线方框作对照，红绿点可并存、各自一条备注。(2) 把卖出信息塞进买入标签导致文字过长挤占且搞乱买点展示，必须分开：买入备注只写如 `15:00 买 89.04`，卖出备注写时刻/价格/盈亏，两日彻底分开互不掺和。(3) 导航左右箭头应以全部交易日的排序列表翻页（全部买入日 + 不与买入日重合的卖出日额外插层），保证每个买入日、卖出日都能单独翻到。(4) 买入点固定在最右端(x=239)，按右边缘逻辑会朝左挤贴边不完整，需强制放在圆点下方居中显示，并保留深色描边(textBorder)保证压在分时线上仍可读。适用场景：任何按日期在分时/日K浮层上标注多笔交易记录的需求。
