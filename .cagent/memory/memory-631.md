stock-picker 结果页需要全量展示（如 3113 只）供用户排序（用户可能先看跌的，不愿翻页）。实施要点：1) 后端下发不再按前 100 名截断；2) 前端只渲染屏幕可见的十几二十行，其余用高度占位撑开，否则三千行加三千只行情/缩略图会卡死手机；3) 排序键必须用选股那一刻算出的涨跌幅（全量都有），不能依赖尚未拉到的实时行情，否则排序结果乱。真机性能仍需用户在手机上实测确认。
