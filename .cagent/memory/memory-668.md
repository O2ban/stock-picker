用户定义的硬条件是：买入时价格必须高于昨收（水上），且降中线本身也必须在昨收上方。历史实现只检查了「价格 > 中线」，中线自己在水下时同样放行，杭州柯林即因此被误选（买在 58.44、中线 56.43，均低于昨收）。修复时须新增「中线自身 > 昨收」的独立判断，作为不可绕过的硬性门槛。
