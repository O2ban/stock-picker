---
分时图纵轴有两种模式：按最大涨停幅度满占（用户不习惯），以及用户常看的通达信普通坐标。通达信口径是纵轴以昨收为中轴上下对称，上下边界根据当日实际波动动态计算并取整；之前纵轴算法纵轴坐标范围错了导致曲线被压扁，修复时应按此动态口径实现，并加无数据时的 base 兜底。
