引入分钟级K线之前必须算清成本：5574 只×每日 240 根=134 万行/天，一年 3 亿多行；对比现有 kline.db 只有 951 万行日线、4.0GB，分钟数据将是 30 倍以上量级，需要认真设计分区、只存近期窗口或降采样，不能直接沿用日线表结构。另外若看盘界面需要实时刷新分钟K线，最佳做法是由前端走腾讯 mkline 拉当日数据，数据库只存历史分钟K线，以避免盘中高频写库。
