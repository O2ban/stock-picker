排查买点策略时发现当天清单只剩一轮 22:46 的运行记录（22只票），不像白天 9:35–10:00 每分钟自动盯盘产生的完整过程，判断为晚间手动重跑覆盖/追加所致。后果：真实盘中统计应以收盘复盘的50只、99只和五日复核为准；若持续手动重跑会把真实盘中记录与重跑结果混在一起，影响后续判断参数到底有没有变好。手动重跑与自动盯盘的落盘必须隔离，避免污染复盘证据链。
