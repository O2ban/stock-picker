stock-picker 修复离线能力后自查发现一个自引入的副作用：服务器自身出错时页面仍显示留存价格，把故障掩盖成正常。修复为两条独立路径——服务器返回错误（服务挂、接口不存在）就把价格置为短横线、状态显示「服务未连接」；只有网络真的不通才用本地留存。验收要点：1) 用户描述的是「关掉应用再打开」，必须用全新进程从启动起就没网做真实冷启动验证，不能只在同一会话里刷新；2) 从没打开过的股票断网时应明说「本地还没有存过行情，联网后再看」，不能显示成 0；3) 人为让接口报错验证故障不被旧价格盖住。
