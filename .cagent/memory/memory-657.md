stock-picker 横滑换股时买点三角（以及顶部行情条）不显示/显示旧数据的根因，是切换股票的瞬间图表仍持有上一只股票的状态（买点、行情），新股票的标记因代码/日期校验不通过被丢弃。修复方向是三条入口（点开、横滑换股、邻票滑入预览）都在切股瞬间同步切换买点与行情归属，并对行情回填做股票代码身份校验，避免旧数据贴到新图上。同类问题也出现在顶部行情条（旧股价格配新股昨收算出离谱涨跌幅）。
