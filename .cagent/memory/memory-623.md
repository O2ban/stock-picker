用户在探讨选股策略时，多次纠正 Agent 对条件的理解偏差（如将“100天平均振幅”误解为“100天内有几天振幅超3%”，实际是“近100日滚动平均振幅值>3%”）。用户明确要求：“先说说你的理解，理解对了才开始”。这表明用户重视逻辑严谨性，反感 Agent 凭猜测直接跑数据。同时，用户倾向于先在小样本（如8只蓝筹股）上验证逻辑可行性，再考虑扩大股池或修改卖出规则，而非一开始就全市场回测。Agent 应在此类任务中采用“复述理解-确认-执行-汇报-讨论”的交互节奏，并在条件模糊时主动提问澄清统计口径。
