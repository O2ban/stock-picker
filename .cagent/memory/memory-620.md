发现振幅副图原公式为“(最高-最低)/昨收”，在日线中即“相对昨收”，在5分钟线中自然变为“相对上一根5分钟K线收盘”，因此计算逻辑可直接复用。但展示层需调整：日线的三条固定参考线（如±10%）在5分钟图上无意义，需重新定义或移除；纵轴范围因量纲变小（通常<1%）需重新计算刻度，避免曲线被压至底部不可见。这验证了“公式自适应、展示层需重校准”的复用原则。
