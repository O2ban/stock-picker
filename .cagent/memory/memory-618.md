在接入5分钟K线周期时，发现本地5分钟数据（约8万根/股）与日线库（前复权）存在价格基准差异：历史区间相差1%~2.6%，仅最新日期一致。若直接用日线数据计算买卖点再画在5分钟图上，或反之，都会导致标记偏离。正确做法是：买卖点必须基于同一份5分钟数据计算，且图表渲染也使用这5分钟数据，确保K线与标记逻辑同源。这是多粒度数据接入时的核心一致性原则。
