用户认可『第一招』（预筛漏斗）后明确表示：先做这个，效果好其他暂时不考虑做。但其核心关切是这套思路能否适配将来类似的选股策略——能否先读某行筛出少量票再继续筛，并强调『这个思路一定要保持』。因此方案应做成通用漏斗：排序顺序由引擎根据策略条件自动推导，用户新写策略、增删条件、调参数时无需改一行代码，且结构上预留多级漏斗的扩展点。
