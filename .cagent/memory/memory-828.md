stock-picker 新浪一分钟批量下载前重新构造股票池时，曾把接口列含义套错，导致筛选结果为 0 只（好在没有因此改动或覆盖现有行情文件）。核实后正确口径是：历史清单第二列只表示当日是否交易，股票类型在基础清单第五列，用这两个正确条件重新取交集才是全市场股票池。教训是凡是跨接口拼股票池，必须逐列核对接口真实返回含义，否则会静默漏掉整个股票池、表现为「没有数据」而非报错。
