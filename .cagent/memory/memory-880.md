复盘用的分钟数据（ev301557-data.json）每分钟只存了价格，开高低收四个字段全是价格，逐条核对确认没有成交量。在线接口历史日期也取不到量能数据。因此分时量能副图只能画框架并如实标注无量能数据，不能编造。如果未来换到含成交量的分钟数据源，量能副图框架会自动出现。
