针对“跌到中间价下方买入”的交易策略，数据分析表明：设置1%的固定止盈会导致胜率虽高（68.4%）但盈亏比极差（0.44），整体收益反而为负；相比之下，等待股价涨回昨日中间价的策略盈亏比更优（0.85）。这表明在短线均值回归中，过早止盈会砍掉主要利润空间。后续优化方向不应是堆叠入场条件或提高胜率，而应通过扩大止盈空间（如等待回到中间价）或加装止损来改善盈亏比。
