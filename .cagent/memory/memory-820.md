在给日内引擎加量能口径时踩过的坑：量能说明文案引用了循环内定义的变量，平时不命中不报错，一旦条件实际命中就会抛异常。凡把「为什么选中」这类说明拼进结果的地方，都要确认引用的变量在拼接点依然在作用域内，不要把只在某次循环里活着的中间量带出去。
