用户对日K的核心不满有两件具体的事：①打开瞬间先画出旧缓存/存盘的图，行情还没盖上去，表现为『停在昨天、缺最后一根』；②价格数字很快跟上，但K线柱子为防闪限制了重绘频率，要好几秒才动一次，表现为『涨了但柱子没变』——这不是慢，是分两步走、第一步没带价。修复顺序按收益排序：先首屏带价，再改日K柱子为局部刷新（不整图重绘），再缩列表刷新间隔。涉及改动原来没提过的服务端缓存与绕过策略时，需按规矩单独征求用户同意后再一并开工。
