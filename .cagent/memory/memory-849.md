stock-picker 的 K 线图组件被多个页面复用（选股看盘、复盘/测试页）时，应把组件改造为可创建多实例的工厂模式，用闭包保存各自状态，而不是复制粘贴代码副本。这样副图、十字线、手势、行情回填等逻辑天然一致，避免维护多份代码导致行为偏差。新增"周线右侧数据页签"、"日K十字线日期标签点击弹出当日分时（浮在副图上层）"等需求都应基于该多实例能力实现。
