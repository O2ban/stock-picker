用户原话要求「每小时加一条纵线」时，agent 先按自然整点加了10:00/11:00/13:00/14:00，被用户纠正：应像通达信那样从9:30开盘起每满一小时一条（故为10:30/11:30/14:00），而10:00那条是用户额外指定的、可以稍微亮一点便于定位。11:30与13:00在横轴仅差约2像素、视觉上是同一根线，只保留11:30。纵线要贯穿价格、成交量、量比三段不中断，且颜色极浅不抢注意力（除10:00外）。做行情图表复刻时，'整点'类需求默认应理解为'从开盘起算的整点'而非自然时钟整点。
