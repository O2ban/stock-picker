在验证交易策略时，必须考虑交易的可执行性约束。例如，如果策略信号出现在跌停板（价格封死在最低限价），散户实际无法挂单买入。如果在回测脚本中仍按收盘价计算收益，会将这些本无法执行的亏损单计为盈利，导致整体胜率虚高（如从真实的53%虚高至65%）。排查策略有效性时，必须剔除不可执行样本（如跌停买入、停牌等）后再计算真实绩效。
