stock-picker 新浪一分钟下载的断点续传曾出现「本批从头请求」的问题，根因是跳过判断把「带扩展名」与「不带扩展名」的文件名混比，导致已存在文件识别不到；数据内容同一天相同，未破坏现存文件。修正跳过逻辑后，已存在的 172 只被正常跳过、本批新增 73 只有效数据。经验：文件存在性判断必须统一文件名形态（是否带后缀、大小写、前缀），否则断点续传形同虚设，白白重打接口且可能触发限流。
