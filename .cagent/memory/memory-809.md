松手换股那一刻，程序用预取好的邻票分时数据先填顶部（避免空白），但该数据不含成交额，首帧成交额只能显示『-』，等网络返回真实行情再补成数值，用户看到先出一版、约0.2秒后变第二版。修复：准备下一只票时同时预取其最新行情快照，松手瞬间填出的就是完整数字（含成交额），后续网络数据回来数值一致、屏幕看不到第二次变化。两条保险：(1) 只把行情接到与自己代码相同的票上，绝不把上一只价格串到新票头顶；(2) 只在分时周期这样接手，K线周期不动（K线换股时旧数据仍在图上，提前塞新股价格会把旧柱子算错）。
