在验证用户自定义的股票分时特征策略时，随机抽样法会导致大部分样本不符合形态特征，无法有效测试策略本身。正确的做法是：
1. 基于用户描述的条件构建筛选公式。
2. 一次性下载并保存全市场当日分时数据到本地。
3. 实施“分层筛选”：先不加严条件，随后逐层加入用户定义的每一个特征（如开盘幅度、缩量、均线位置等），记录每一层的通过股票数量及当日平均收益。
这种方法能清晰地揭示哪些条件是有效的增强因子，哪些是无效的或有害的，从而避免盲目打磨无效条件。
