（本条更正并取代此前「日K量也错」的结论）

北交所量能bug的真相，经抓取腾讯实时行情与分时原始报文反推确认：
- 北交所 bj920006：分时累计量 21685 ÷ 日K vol 21684.99 = 1.0000，两者完全相等、同为「手」口径；成交额÷量÷现价≈101.6≈100，与沪深 sh600019（≈99.0）完全一致。腾讯给北交所的量本来就是「手」，和沪深一样。
- 日K库的量是正确的，此前怀疑「日K量也错」是误判——amount/vol÷股价≈100 恰恰证明库里存的就是正确的「手」。

真正根因（只有分时解析这一处）：parseTimeline 第173行把 volDivisor 初始值写死为 100（按「股」处理）。北交所分时只有3个字段（时间 价格 量）、没有成交额，靠「成交额÷量」反推单位的探测循环因 f.length<4 全部跳过，volDivisor 停在默认的 100，把本来就是「手」的量又除以100，导致算出的 vol 偏小100倍。

修复方式：无成交额可反推时按板块给默认单位——北交所=手（除数1），科创板=股（除数100，因科创板上游确实返回「股」需÷100）。实时行情代理 parseQuotes 第52行 volDiv 默认已是1（手），本身正确，只影响科创板，无需改。验证：重拉后北交所成交量与日K完全一致（bj920050=5728手、bj920249=29291手、bj920642=11443手、bj920832=28098手）。
