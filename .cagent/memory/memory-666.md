把当日选出的股票按触发时间分桶，统计各桶相对买点的平均收益：本例 09:50、09:51 两批最差（-2.4%~-2.7%）且数量最多，09:59 那批最好（-0.37%）。这两批恰是大盘开始下行时选出的。

结论：选股时点（触发时刻的市场状态）与数量分布本身就是买点质量的可控变量，可在策略里加入「单位时间出手数量上限」或「避开大盘快速下行时点」的约束，而不只是调买点阈值。
