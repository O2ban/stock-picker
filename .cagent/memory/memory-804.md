stock-picker 清单界面点开看盘后的分时图买点标记规范：由绿色三角改为直径约 7 像素、带深色描边的小圆点，圆心落在成交价所在的曲线位置上，不向下偏移；不再显示『放量上拉』这类触发原因文字，改为『时刻 + 买点价格』（如 ``09:38 30.77``）；触发时刻落在最左段或最右段时文字自动移到圆点侧边避免被画布边缘裁掉，文字保留深色描边以便压在曲线和昨收虚线上仍可读。清单列表的说明列和复盘页的成对买卖点标记属于另外两套，不在本次范围内。该规范已实际验证与清单记录的触发时刻、触发价一致。
