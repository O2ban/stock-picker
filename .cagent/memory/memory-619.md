---
5分钟周期下，同一天有约48根K线，若仅用日期作为索引键，会导致多根K线重叠在同一坐标格，十字线拖曳和买卖点标记将随机落在某根上，造成视觉错乱。解决方法是在数据加载阶段为每根5分钟K线拼接唯一的`date + time`标识，并将该标识用于坐标轴映射、十字线像素换算及标记定位。此模式适用于任何从日级细分为亚日级的图表改造。
