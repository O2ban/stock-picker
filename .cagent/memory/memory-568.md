分时图例的成交量一行原来显示全天累计量，与同一行的价格、均价、量比（都是当前时刻口径）不一致，十字线一停一放还会来回跳。修复为统一成当前这一刻的成交量（已确认对应最后一根/最近一分钟柱子），全天累计量在顶部行情条里本来就有。最高、最低两项从下方这一行去掉（顶部已有）；但顶部行情条的最高/最低属于全天汇总，必须保留——两处口径不同、不可混删。图例按副图分行时公式线（中/PP/HH/M20）必须留在价格图那一行。另需注意图例上其它读数在取消十字线时也可能漏刷，restoreLegendLatest 要一并处理所有读数项。
