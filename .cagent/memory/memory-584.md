子代理异常终止后，先检查文件时间戳（本次仍是几天前）判断它是否动过代码——未动手则无破坏性影响可直接重派，不会留下改一半的麻烦。重派时把实施规格写严格，特别是上次没交代清楚的关键点（预筛必须补实时行情最后一根 K 线）。三条不变量需写入笔记并随任务下发：只淘汰确定不合格的股票、数据不全一律放行、最终名单必须与现在完全一致。子代理返回后由主对话用同一策略开启/关闭预筛各跑一次逐只比对名单，名单差一只就不上线。
