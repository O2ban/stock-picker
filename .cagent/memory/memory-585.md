stock-picker 所在机器内存只有 3.7G，而总资料库 4G 多，装不下，老数据总被其他服务挤出内存，这就是『隔一阵子不用就慢、连着点就快』的根因。预筛漏斗完成后读进去的数据量能降到原来的两成以下，需要搬进内存的部分随之减少，冷热落差自然小很多，因此判断只做预筛这一招就够用，暂不做其他优化。另注意：这台机器上的选股服务没有用正规守护方式托管，而是靠『后台孤儿进程 + 每小时探活一次』运行，改完代码重启时需按这套方式处理并确认探活脚本仍能发现它。
