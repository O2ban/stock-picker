用户最初设想用「高昨比」（当日最高价相对昨日收盘的涨幅）筛选活跃票，认为幅度大即赚钱空间大。全历史回测显示：收盘买入、次日 +1% 挂单卖，扣费后平均每笔亏 0.32%；+1.5%/+2%/+3% 各档止盈全亏，止盈越小胜率越高但亏得越多——「高胜率」是止盈目标定得小带来的必然结果。用户看到的某票连对 26 次是选取窗口造成的事后挑选（且当时它的高昨比只有 1.78，根本不满足条件）。高昨比高的票确实更容易次日摸到 +2%，但同样更容易次日收得更差（波动双向）。正确用法：定止盈点数、仓位、网格适配度，不适合用来挑方向。全市场排序验证显示按高昨比排序会精准选出最差的一批票。
