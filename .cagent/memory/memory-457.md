用户要求周K也能看到本周实时。注意：周K是一周几根日线合并出来的，直接把今天的价硬塞进去会把该周的成交量、涨跌幅、均线全部算歪。正确做法是『本周这根柱子 = 本周已走完交易日的数据 + 今天的实时价』在展示层动态合成，并且明确不写入缓存，否则收盘后缓存里会留下一根假的周K柱。此改动涉及计算规则，应与常规改动分开单独做。
