用户提出的“当日买入下跌、当日卖出上涨”的日内做T思路在A股不可行，因为当天买入的股票当天无法卖出。真正有效的做T本质是围绕底仓进行日内回转交易：需先持有底仓（如1000股），在高位卖出底仓部分，在低位买回，每笔交易都是调整现有持仓数量。这不仅是合规约束，也决定了策略盈亏的计算方式——需计算总仓位市值变化与来回交易价差之和，而非逐笔独立计算。在实现此类策略时，必须强制校验“卖出数量 ≤ 当前可用持仓（排除当日买入部分）”，并明确底仓来源与大小，否则回测结果将严重偏离实盘。
