11-18筛出的47笔按T+1结算后对比：次日开盘卖平均每笔亏0.69%、胜率27.7%；改成次日收盘卖则平均亏2.78%。差约两个百分点，足以把「次日开盘卖」定为主口径。注意这是建立在单日样本上，但与「A股T+1当天不能卖」的硬约束一致，任何按当天买当天卖计算的收益/止损/止盈都是不可执行的假交易。
