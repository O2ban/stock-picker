在股票策略回测中，不应只看整体胜率，必须引入大盘环境因子（如连跌天数、趋势位置）进行分组统计。实测发现，某基于均值回归的策略在平稳大盘中亏损，但在大盘连跌6天以上时胜率高达72.8%。这说明策略本质上是逆势反弹策略，只在特定宏观状态下有效。优化策略的第一步应是增加大盘环境过滤器，而非个股形态条件。
