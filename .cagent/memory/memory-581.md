现象：选股冷启动13秒、热态3秒，而策略最长回看75个交易日、全市场数据仅三四十兆，顺序读只需1秒。根因是总库按日期存储，查全市场某窗口等于五千多次随机跳页；第二次快只是因为页缓存命中。

三个方案按收益排序：
1）先粗筛再精算（收益最大、不依赖换库）：策略中「今日收阳、涨幅0~6%、量比1.0~1.5、现价贴近MA20」等只看最后一行的条件，先在每家最后一行上过一遍，五千多家通常只剩三四百家，再对它们翻完整窗口。读量降八成以上。
2）独立小热账本（约250个交易日、110MB，按股票聚集存储、常驻内存）：价值主要在消除冷启动，热态下与大库差别不大（1.3s vs 1.0s）。若做，回看窗口必须留一年，不能按当前策略的75天剪——不同策略回看长度不同。它只是选股专用快速副本，历史回溯和回测仍用大库。
3）空闲预热：每十来分钟轻碰小账本，是方案2的配套，单做无意义。

结论：先做方案1，看做完还剩多少再决定是否建库。
