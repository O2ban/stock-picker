判断一批选股结果好坏时，应并行看两个维度：
1) 相对大盘的超额——若大盘普跌 2.5% 而清单只跌 0.6%，说明选股方向有效，不因下跌而否定。
2) 相对买点的盈亏——买点在当日价格区间的位置（如 78%~83% 高位）决定实盘结果；市场转弱会把买点亏损成倍放大。

由此得出两条处置原则：
- 限制买点涨幅上限、压缩每日出手数量，避免买在高位；
- 加「大盘当天跌幅超阈值就不出手，或只做防守型板块」的开关。

另注：下跌日抗跌的往往是航空、食品饮料等防守板块，可作为弱势环境的候选池参考。
