stock-picker 量比副图自绘两个极值数字时出现过一个真 bug：先把两个数字的位置算好并做了防重叠处理（两个数字高度太近时强制分开成两行），但写回 DOM 时用的却是未处理的原始坐标，导致防重叠逻辑完全失效。当量比全天几乎横着走、最高值与最低值高度挨得很近时，两个数字就会糊成一团。修复原则：凡是「计算 → 后处理 → 回写」三步链条，回写必须使用最后一步处理后的结果，中间变量不要被原始值覆盖。验证方法是专门构造极大值与极小值接近的窄幅数据渲染一次。
