用户的分时早盘买点策略本质是1分钟级别（量能结构、站上水面、突破前高、买点时间全部只看当时已形成的1分钟数据），5分钟K线会抹平瞬时极值，只能作粗参考，不能称为分钟级验证、不能作为正式回测依据。买入价取触发那根1分钟K线收盘价（保守版可另测下一根开盘），双边费用0.26%。此前曾误把「已有5分钟历史数据」当成「策略是5分钟级别」并提出按5分钟全市场试下载，被用户纠正后撤回——遇到类似情况应先确认策略实际使用的时间粒度。
