用户重点关注十点量比是否达到 3、以及量比是否大于 1，因此量比副图必须有 1 和 3 两条横向参考线（3 用更亮的金色）。纵轴从 0 起步、一格一个单位、顶部至少留到 4 让 3 有落脚空间，量比特别大的票自动扩到 6 或更高；要避免刻度取成「两格一档」导致 3 不落在整档上，上限不应落在非整档值。轴区间算法应抽成共用函数（与价格轴对齐）避免两处计算不一致；盘中实时刷新量比冲高超过当时上限时，曲线顶部会被裁掉，需让轴自动跟随扩张且只长不缩，避免临界值附近反复跳动导致刻度闪烁。
