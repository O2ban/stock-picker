分时图新增副图读数时发现成交量副图的三个实际问题：实时 tick 更新下成交量轴缺少锚点保护会自适应漂移；副图底边可能显示出负值（如负成交量读数）；存在未使用的死代码。修复方式：给成交量副图改用与量比副图相同的固定刻度策略，并把成交量轴接入每 3 秒 tick 的越界检查；读数标签限制在画布内并裁剪溢出部分。属于「新增面板类绘制」的通用防御点。
