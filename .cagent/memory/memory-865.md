复盘页 rv.js 方案展示层的设计约定：每个方案在列表上方分三块结构化展示条件——① 买入门槛（列出该方案要满足哪些条件才买，如双过滤方案的'高昨比≥1%'和'收盘不跌破MA5/MA20'，对照方案标'无门槛'）；② 买卖规则（买入价=15:00收盘价、止盈触发价=买入日收盘×1.01、三种卖出情况：触及价成交/跳空高开按开盘价/全天未触及按收盘、卖出日是哪个交易日）；③ 交易成本（双边合计 0.083%，已计入净收益不再另扣）。每换一个方案这三块跟着刷新，各自口径对得上。费用文案用 feeText() 辅助函数统一生成。此设计源于用户纠偏：条件不能只写在 note 里笼统描述，必须把具体过滤项逐条列出。
