stock-picker 曾有疑点：科创板成交量在原始数据里单位与其他板不同，后端取数层已修正。若前端在叠加实时行情算均价时又按老办法乘 100，均价会被缩小一百倍、曲线再次被压扁。实测三只票（科创板/创业板/沪市大盘股）按现算法得到的均价与真实价位同量级、也与分时数据算出的结果完全一致，说明前端这一处恰好与后端修正互补，保持原样、改动反而会错。
