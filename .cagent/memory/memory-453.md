量比分母口径修复：分时量比 = 累计成交量 ÷（vol5 ÷ 242 × 已走槽数），其中 vol5 的均值分母原先按『有成交的天数』计算，导致停牌较多的股票被系统性低估。改为按交易日数计（停牌日成交量按 0 计入 5 日均量），常规股票新旧算法取值相同，只有停牌多的票更准确。修改 server.js 后必须重启服务才生效。开盘瞬间量比会出现尖刺（首分钟累计量 ÷ 5 日均量×1/242）属通达信标称口径，不是 bug。
