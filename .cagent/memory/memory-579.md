stock-picker 上一轮『分时换股』探针实际全跑在日 K 上：脚本用按钮文字等于『分时』判断点击，而 DOM 里按钮组文本是『分时日线周线』连在一起，永远不相等。教训：自动化探针不能只发点击，必须按属性/结构定位目标元素，并在动作后回读实际周期/状态确认切换成功，否则结论适用范围全错。同理，测试选错元素会导致『看盘页验证没真正打开图表』这类假结论。
