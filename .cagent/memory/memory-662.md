分时策略新增两条规则（出手前跌超3个点不选、买点须冲过买之前那一刻分时最高点）后，全量99只统计：平均+0.19% 跑赢大盘（-1.57%）1.76个点，方向正确；但按买入价计算平均亏1.24%（含费1.50%），胜率低且亏损额大于盈利额。买入价平均位于当日最高最低区间的79%处（过半在84%以上），即'突破那一刻'往往就是短期高点。另发现'买入涨幅越低越好'不成立（1%~1.5%档反而比1.5%~2%档更差）。结论：选股层已能贡献约2个点超额，被买点吃光；后续应换买点思路（如突破后回落不破前高再买）而非继续微调参数，且必须用历史数据验证不能凭单日下结论。
