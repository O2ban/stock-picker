用户看到某只票当天涨 12% 而没被选中时，会问「是不是因为不是主板票」这类猜测。回应要点：先直接给结论（与板块无关），再用真实数据逐条排除程序缺陷，最后诚实说明这类票属于「事后看最漂亮、事前最难拿住」的类型（低开 5 个点时多数人不敢接），点出策略与用户胃口的分歧所在，并把「是否为这类走势单开一套验证」作为独立的后续事项交用户决定。
