对全市场逐只拉新浪1分钟数据时，实测每只约0.4秒，但网络异常比例随量升高（如175只中160只完整落盘、1只无数据、14次请求失败），且单次执行约2分钟会被时限中断。做法：按历史股票清单小批次落盘并续传，失败代码单列重试队列，绝不能把请求失败计为「停牌」或有效样本；只有覆盖率达标后才能回测。已落盘文件每只应有231-238根1分钟K线，另需关注剩余磁盘空间。
