在 stock-picker 或相关量化交易项目中，若策略逻辑依赖盘中分时数据（如分时均价线、日内最高价回落幅度），现有的全市场日线库（约1000万条记录，无一根分钟线）无法满足需求。调研发现免费公开行情接口的分钟数据历史深度有限（5分钟线通常只有最近6天-1个月，15分钟线3个月，30分钟线半年），不足以支持几百个交易日的回测验证。因此，实施此类策略前必须引入支持长历史（如回溯至2015年）的开源分钟线行情数据库，否则回测结果仅是噪音，无法得出有效结论。
