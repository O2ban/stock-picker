stock-picker 新浪一分钟批量下载实测约 92/100 成功率，其余 8~27 只返回分钟线不足 230 根。这类情况不能直接算成停牌、也不能算成无数据或有效样本，必须在覆盖核查阶段结合全市场当日交易状态名单，归类为停牌、上市较晚或接口缺数，再决定是否重试。原则：网络失败/缺数不得伪装成「无数据」，否则会污染回测样本与出票结论。
