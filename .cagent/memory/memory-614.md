在开发股票复盘/回测功能时，如果图表本体（K线/均线）使用的是服务端统一口径的日线数据，而买卖点标记是基于前端手写的分钟数据或另一套复权逻辑（如本地计算的复权基准不同）得出的，两者在视觉上会出现严重的价格错位。这种错位不仅让标记失去参考价值，更会导致基于该标记的任何交易结论都是错误的。经验法则是：凡是需要在图表上叠加基于价格计算出的标记（买卖点、支撑阻力、均线交叉等），其计算所用的数据源必须与图表本身展示的数据源保持‘同源’（Same Source, Same Adjustment Basis），哪怕这意味着需要放弃更细粒度的分钟数据，也要确保基准一致。
