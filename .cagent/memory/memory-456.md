用户提出『有了分时3秒更新，为什么日K/列表还要慢通道，最新价应统一一个更新渠道』。正确结论：不要统一到分时数据（分时接口一次只能拿一只股票、返回全天几百个点，几十上百只的列表用它会被上游打爆），而要统一到『同一份批量最新行情快照』——列表、缩略图、日K、周K、分时图顶部报价全部读它，保证同一时刻各处价格数字一致。分时曲线自己的分钟数据只负责画线，不再负责提供价格。刷新频率不能统一成3秒：单只查询数据量小无所谓，批量列表3秒一刷会导致价格乱跳、手机发烫耗电、上游限流，必须按场景分层。收益排序的落地项：①打开日K首屏带上已有价（不再缺最后一根）②日K柱子改局部刷新跟快节奏不整图重绘③列表刷新60秒缩到20~30秒④周K补『本周未走完这根』。
