预筛虽然把五千多只筛到四百多只、省下了精算成本，但冷态下预筛自己需要把全市场最近十天的数据从硬盘过一遍。实测冷态读盘量分层：预筛扫全市场约6秒（占七成时间），精算四百多只仅1.6秒。根本原因是库里数据按日期排列，取「每只股票最近十天」等于让硬盘在几十万个位置之间来回跳着捡，机械盘最怕随机IO——81MB纯顺序读本来一两秒就够，随机读却要8秒。热态时数据已在内存，这一翻只花半秒。这解释了为何预筛能大幅降低精算开销，却无法消除冷启动的全市场扫盘瓶颈。
