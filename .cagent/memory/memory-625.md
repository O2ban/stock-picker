11-12 的回测中 313 只里 250 只下跌、平均日内跌 0.98%，随便在 9:35 买入持到收盘平均 −0.94%、胜率仅 24%。在这种全市场下跌日，「缩量小实体、冲前高才买」这类条件本就几乎不出票，出0只是市场环境使然。结论：评估策略时必须同时给出当日全市场涨跌分布和「随机买入」基准收益，把策略表现与市场环境分离开，否则会把普跌行情误读为策略失效。
