11月19日普跌日（大盘-1.6%）同一策略对比：加「买点距最低点≤2.5个点」选50只、胜率24%、平均亏1.58%；不加选99只、胜率14%、亏2.44%；被挡掉的49只平均亏3.32%仅2只上涨。该条件用决策时已发生的价格计算、不含未来函数，判断方向正确但仍属「少亏」，且当日50只到收盘平均只跌0.06%（优于大盘），说明选股本身抗跌、亏损一半来自下午继续走弱。结论：邻近度因子有效但不足，不能据单日样本下「已找到盈利解」的结论。
