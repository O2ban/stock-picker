需求形态：量比行图例显示「量比 0.58　10点 1.27」，前者跟随盘中实时刷新，后者读死10:00那一分钟的位置、盘中刷新只动前者不动后者，因此不会抖动；十字线指向任意时刻时图例同样带这个固定值。未到10点或当日10点数据尚未到位时显示'-'（注释里要写清真实原因是数据未到位而非时间未走到）。验证方法：把真实数据人为裁剪到09:35复现开盘场景，确认显示'-'且页面无报错；模拟连续刷新确认数值稳定。
