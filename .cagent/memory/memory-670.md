评估新增条件的有效性的做法：以当前全部选股为基准（如 127 只、相对买点 -1.57%），每次只加一条过滤，观察剩余数量和相对买点收益的变化，再组合多条看综合效果。关键陷阱：单日普跌行情下的对比结果不能作为结论（如「突破前高」当日反而更差，原因是能冲过前高的票往往已拉高），必须连续多日验证。同时应向用户如实说明哪些条件在自己提出之外的（如「水下时间不过半」）效果最好，交由用户决定是否纳入。
