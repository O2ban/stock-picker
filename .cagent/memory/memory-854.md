对比了180只票·日的存档分时与日K（kline.db daily_kline，前复权），结论：开盘价/收盘价全部精准一致（同一份行情）；最高价/最低价约80%的票有几分钱到一毛的细微偏差（如宝钢某票分时最高19.15 vs 日K 19.25）。根因：腾讯分时接口每分钟只给一个「分钟末成交价」，最高最低是从这些分钟末价里挑的，盘中瞬间冲高又收回的尖刺分时看不到而日K能捕捉。对回测影响：用「买点距当日最低不超2.5个点」这类规则时，日K最低价比分时看到的更低一点，回测略偏保守；收盘价无此问题。换存档方式救不回来，必须换能给单分钟OHLC的数据源（见通达信.lc1相关记忆）。
