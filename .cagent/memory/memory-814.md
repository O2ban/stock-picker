stock-picker 分时策略核查后遗留两项必须由用户决定的条件：
1) “冲过买点之前的最高点”当前只要求“高一点点就算”（p > preHigh），若要“明显冲出幅度”需补阈值（如 0.5 个百分点）。此项影响很大——历史剔除的票里很大一部分卡在这里。
2) “孤零零一根大阳量不构成买点”只落实了缩量段（≥3 根）和上拉段（≥2 根），最前“先放量”段未设最小根数，理论上单根可算。若补上（如要求放量段也 ≥3 根成堆），代价是票更少。
按用户一贯纪律（不许擅自改条件、每次只改点名的几条、先说后改），这两项在用户明确答复前保持现状，不得自行加阈值。
