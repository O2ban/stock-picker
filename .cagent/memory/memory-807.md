在讨论盈利票特征时，agent 用『昨天收红 vs 收绿』对全市场做统计、并提到回看三年数据，被用户严厉纠正：用户要的分析对象是『按当前选股+买点策略真正选出来的那批票』，再看其中最后盈利的票具备什么特征，且必须是多因素叠加考虑而不能单看某一因素。且免费分时接口只保留最新一个交易日，无法真正重建历史上按分时买点策略选出的票。做盈利归因分析前必须先确认分析对象口径（策略产出集 vs 全市场）与数据可得性，不能偷换成别的样本。
