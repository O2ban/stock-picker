stock-picker 量比副图轴范围的核心权衡：如果为了避免把 1.0/3.0 参照线裁掉而强行扩大轴范围，当某只票全天量比都在 1 附近时整条曲线会被压到副图最底部只剩一条细线（历史上专门修过这个问题）。最终采用「一条横线最多让轴多延伸三成」的规则：代价不大就把 1.0 和 3.0 纳入轴区间；代价太大就让参照线自动消失、不再绘制。这是有意取舍——曲线形态可读性优先于强行露出参考线。副作用是窄幅票（0.9~1.2）看不到 3.0 线。
