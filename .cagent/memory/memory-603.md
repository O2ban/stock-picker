stock-picker 分时策略的实盘出票率约为全市场 0.4%（5000多只一天出20~100只）。按此比例，313只样本的期望出票只有1只左右，跑出0只完全在正常波动范围内，既不能证明策略无效也不能证明有效。要得出可信结论，样本需扩到 1500~3000 只（按每只 0.3~0.45 秒下载速度约二十分钟、约 90MB 磁盘）。同理，单日或少数几只票的测试结果不具备统计意义，不能用来定策略好坏。
