为满足回测需要单分钟最高最低的需求调查了三个免费渠道，核心发现：通达信1分钟线文件（.lc1）每分钟一条记录、32字节，明确存这分钟的开/高/低/收四个价加成交额和成交量，所以只要数据来自通达信体系就能拿到单分钟最高最低——这正是腾讯分时接口给不了的。三个渠道都基于同一套通达信数据，区别在封装：tdx2db（导入本地DuckDB/ClickHouse，但只能从安装那天起往后累积）、free-stockdb（打包好的本地库，宣称含沪深京7000+股票1/5/15/30分钟且有历史，下载即用但未验证真假）、tdx-mcp（偏今日、北交所覆盖不确定）。关键限制：通达信官方不提供历史分时下载，过去的日子要靠别人提前攒好的库补。注意与本机已有的 eltdx 组件能力对照（eltdx 可取任意历史交易日1分钟K线），选型前先确认 eltdx 是否已能满足，避免重复引入新工具。
