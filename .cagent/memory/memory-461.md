stock-picker 分时图滑动换股后新股票自动冒出十字线：换股时确实清理了十字线，但只要界面再发生一次尺寸变化（手机地址栏收起、转屏、分屏切换），重排那一步会无条件重画十字线。它只检查「十字线对象是否曾创建过」而不检查「现在是否真的该显示」，而用于定位的下标已被清成「无」，绘制时又被兜底成第 0 个位置，于是每次都在开盘第一分钟画一条竖线并锁定状态，还会让之后的横向拖动变成挪动十字线读数而非换股。修法是在绘制入口加两道判断：未锁定、且存在有效位置才画。复现需走真实路径：先点亮十字线→再取消→再从副图区域横滑换股→最后改变界面尺寸；撤销修复时两道防护必须同时撤销才能复现。
