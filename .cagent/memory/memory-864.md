为让复盘页列表上方显示每个方案的回测区间与筛选条件：(1) 方案描述字段 note 原本是纯文字，前端给它加「筛选条件：」标签后再渲染，让口径文字有明确标识；(2) 回测时间区间不在方案文件里，需从证据数据（各方案覆盖的全部买入日）取最小/最大日期算出真实起止，写进 rv-plans.json 而不改证据数据本身；(3) 各方案覆盖的买入日不同导致区间不同（主方案可能 6/25~11/18，对照方案多一天到 11/19），不能一刀切套同一个日期；(4) applyPlan 里要同时处理无方案选中时清空区间与标签，避免残留；(5) 改完升级缓存版本号。排查入口是先查方案 note 是否含条件文字、再确认时间信息实际存在哪份数据里，而不是假设方案文件自带。
