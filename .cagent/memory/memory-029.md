---
场景：为选股界面增加'选股基准日'控件，允许用户选择历史日期回看策略在该日会选出什么。发现两个隐藏的前视偏差陷阱：(1) 完整周线/月线含'未来数据'——若基准日落在某周的中间（比如周二），数据库里那根完整周线含该周后面几天（周三到周五）的收盘和成交量，直接参与均线窗口就会污染结果；(2) 当前周拼接去重字段名写错——去重判断从未生效，导致每个基准日下当前周都被重复插入，20 周均线实际是 19 个不同周 + 1 个重复。修复方向：历史基准日下必须剔除尚未完成的完整周期条，去重条件对齐真实字段名。同类'回看/回测'功能（如策略回放、事件驱动研究）通用。
