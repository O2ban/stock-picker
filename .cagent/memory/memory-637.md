在50只符合新条件的票中按买入时当日涨幅分档：涨1~1.2%共26只平均亏1.99%（最差），涨1.2~1.5%共18只亏1.74%，涨1.5~2%共6只赚0.07%（唯一不亏）。上午快照与收盘两次结论一致，不是偶然。说明「越早发现起手越好」的直觉在分时买点场景不成立，涨幅门槛过低下沿会拉进最差的一批。
