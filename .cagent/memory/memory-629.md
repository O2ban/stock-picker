用户要看日内强势票的图形，现有选股链路只认日线，日内条件需单独接入一条路径。落地经验：结果列表每行除涨幅外还应带「第几分钟触发、哪种触发（翻上水面/过分时前高）、触发时涨幅」的小标签；点开分时图要在触发那一分钟的价位画买点标记（绿色小三角）。验证标记正确性要换股确认标记跟着换（第一只标 9:54 价位 3.60，第二只标 9:35 价位 8.18，无残留）。全市场分时抓取约 5-6 秒，应输出百分比/已耗时/预计剩余进度日志。
