用户对 stock-picker 看盘的明确需求：要的是分时图（不是分钟K线柱子），用腾讯源，看盘界面的票每 3 秒更新一次价格；自选股和其他新查询的股票打开分时时应加载分时曲线并同样每 3 秒更新，效果对齐通达信——价格更新及时、体验友好。在动手前必须澄清「一条每分钟跳动的价格线」与「一根一根的分钟K线柱子」是两件事：前者只加一个腾讯接口约半天工作量，后者要新建分钟表+增量下载任务，是三到五天的工程量。
