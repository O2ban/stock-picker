301557复盘数据的分钟序列只存储了收盘价（highs/lows/opens是days的副本，非真实高低开），因此前端重算引擎只能用分钟收盘价判定止盈止损触发。这导致重算结果与原静态方案数值不同（如「止盈1%无止损」重算胜率66.7% vs 静态78.4%），因为静态口径用了「分钟最高价/开盘价」判断触发。这不是bug，是数据本身的限制，界面上已明示。同理止损只能按分钟收盘价触发，无法判断分钟内瞬时低点。
