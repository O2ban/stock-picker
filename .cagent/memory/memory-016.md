用户明确要求选股范围在界面上可配置，不需要看很久的票，全市场逐只扫描既慢又不符合实际使用习惯。设计原则：范围缩小应放在扫描最前面，让后端只拿需要的股票进入计算，而不是计算完再过滤。实现需要检查现有前端字段、后端参数和引擎入口，将'选股范围'作为引擎的前置过滤条件而非后置结果筛选。当前页面虽然有板块选择但缺少真正的选股范围配置功能。
