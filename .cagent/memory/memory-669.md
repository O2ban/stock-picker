用户纠正对策略的口径理解：'水上'指的是价格在水上（不是降中线在水上）；买点必须同时满足①价格站在水面上、②价格高于降中线、③冲过买之前那一刻为止的分时最高点。新增排除条件：出手前曾跌到水下3个点以下的股票直接不选，没跌破的仍可考虑；买点涨幅上限仍为3个点。清单排序按实时涨幅，暂不加'水下时间'维度。用户强调沟通要先看清其原话再动手，不擅自展开条件。
