分时图观感偏扁的根因不是振幅小，而是纵轴算法把昨收价强行纳入区间（高开 0.18 元导致下半区全空，实测填充率仅 53%）。改为满占坐标（区间跟随真实价格、昨收仅在距区间≤12% 时纳入、档位 1/1.5/2/2.5/3/4/5/6/8、格数 4~9）后填充率升至 80%。同时须修：interval 必须与对齐后的 min/max 用同一步长，否则会标出 25.2125 这类无法阅读的刻度。背景知识：通达信默认「普通坐标」严格以昨收为中轴对称、无余量（HQChart 复刻即如此），因此跳空票一半空白是默认行为；要铺满必须用满占坐标，代价是昨收线在跳空时可能跑出画面，具体选哪种取决于用户更在意「铺满」还是「昨收可见」。
