用户实际操作是每次收盘买一只、持有一只、不补仓、卖掉当天收盘就能买下一个信号。曾误算成「卖出后要等第二天才能再买」的 55 笔版本（该口径作废，当天卖出当天可再买）；也曾在理论口径下报告 +11.3%。按真实约束重算为 101 笔（120 个交易日内共 114 个信号，13 个因还持仓而错过属正常），胜率 81.2%、扣费后 +13.8%。教训：回测的样本口径必须匹配用户的资金与持仓约束，且要主动区分「理论满信号」和「实盘可执行」两种结果。
