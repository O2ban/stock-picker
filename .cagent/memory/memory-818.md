用户对日内引擎量能结构的新口径：
1. 先放量段必须是连续区间且至少 3 根，只看成交量，不区分阳柱阴柱。
2. 从先放量段到买点的整段结构逐根检查，若某根量柱同时达到左右相邻量柱约 2 倍及以上，判为孤立异常尖峰，不允许靠它撑起量能结构。
3. 两个阈值都必须进策略配置而非写死在程序里，后续可调。
4. 关键实现细节：检查只能使用买点当刻及之前已出现的量柱，不能读买点之后的未来数据；盘中数据只到当前分钟时，异常量柱要与它当时已出现的左右邻柱比较，不能把当下这根量柱当成未来邻柱。此点若写错会引入前视偏差或误判。
