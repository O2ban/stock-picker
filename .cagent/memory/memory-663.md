评估选股策略的买点问题时，应做三组对照：(1) 持仓涨跌 vs 全市场平均涨跌，用于判断选股逻辑本身是否有效（本次 127 只平均 +0.67%，全市场 5574 只仅 797 只上涨、平均 -1.30%，超额 +1.97pp，说明选股有效）；(2) 买入价在当日最高最低区间中的位置百分比，用于判断买点是否偏高（本次均值 78%，中位 83%）；(3) 买入后最大浮盈/最大浮亏及从未浮盈的比例。并用事后模拟止盈止损验证卖出时机是否为瓶颈。这样才能把「选股能力」与「买点能力」分开归因，避免盲目调参。
