stock-picker 分时看盘的 msUntilMarketOpen 最初只处理「未开盘」两种情况，不覆盖「盘中」。当上午因上游快照滞后被误判为休市时，10:00 之后该函数直接返回次日 9:15，13:00-15:05 之间一个请求都不发，整个下午的轮询被锁死。修复模式：1) 保留一条低频（8 分钟）探测，防止误判后永久无法恢复；2) 3 秒轮询拿到当日数据时做正向自愈，只解除误判、不判休市，避免单只停牌股被误判；3) 非交易时段用「等开盘」定时器代替轮询，到点自动醒来。这类「按时间分支判断交易状态」的函数必须把盘中午休、尾盘、误判自愈都写全。
