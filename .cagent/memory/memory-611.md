在 stock-picker 项目的复盘页面开发中，助手初版将 K 线图嵌入页签并试图在一屏内显示，导致移动端体验极差。核心问题有二：1. 图表占满屏幕且开启了触摸拖动/缩放手势，导致用户手指在图表上滑动时会被图表捕获（作为拖拽），页面无法上下滚动，列表无法查看；2. 用户期望图表的交互手感（平移、缩放方式）与主看盘界面完全一致，而非助手自创的底部滑条方式。最终解决方案是：在移动端禁用图表内部的触摸手势接管（将滑动权交还页面），并直接复制主看盘界面已成熟的图表交互逻辑（如横向拖动平移、双指/上下滑动缩放），以确保全应用体验统一且符合用户直觉。
