用户对日内自动盯盘的核心验收要求是「出手可回看」：清单页按当天列出被策略挑中的票，每只显示名字代码、触发时间（几点几分）、触发时涨幅、形态名、小分时缩略图、当前涨跌幅和现价，并支持按涨幅排序（高→低→低→高→原始顺序循环）；点某只票进入分时页，在触发那一分钟的价格位置画出买点标记（绿色三角＋如「09:58 放量上拉」的文字）。

配套要求：自动盯盘在约定时段（9:35~10:00 每 5 分钟一次）自动跑，结果按代码去重累加记到当天账上，不重复记录。实现细节上，标记文字需加深色衬底避免与均价线/昨收虚线糊在一起，且触发时刻在最左段（9:35~10:05）时文字要自动挪到三角右侧，否则会被画布左边缘切掉——这两点都是用户实际看图会遇到的显示问题。
