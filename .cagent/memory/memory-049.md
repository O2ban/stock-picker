cagent 的多节点样式，用户明确要求：位置放在输入框下方（底栏左端的一行灰色小字），形态参照截图做成下拉式——图标 + 当前节点名 + 下拉箭头（如「🖥 云端电脑 ⌄」），而不是平铺一排带分隔符的 chip 组。

通用经验：涉及视觉还原的需求，用户会以参考截图为准；先看清截图中的具体形态（下拉 vs 平铺、位置、层级）再动手，避免实现成「位置对了但形态不对」还要返工。
