用户要求「在应用里逐日看分时、分时上用小圆点标记买卖点（带时间与买卖价、卖出额外标该笔收益）”，并和已有页面统计对比核查。核对应覆盖四层：1）分时价格逐点比对（100 笔×240 分钟）；2）圆点位置与读数（绿点=当天收盘买入、红点=拐头确认卖出、橙点=首次触及 +1%）；3）统计数字（总笔数、平均/中位、胜率、累计、拐头卖出与未触及收盘卖分类、高昨比分档）；4）口径差异需主动提示，例如分档表六档加起来 99 笔比总数 100 少一笔（第 1 笔往前找不到前一日收盘价，算不出买前最高涨幅），需让用户决定取舍。同时要坦白 agent 无法替代手机实机滑动体验，需用户实测。
