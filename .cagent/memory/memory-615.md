在股票策略回测中，‘近一年表现好’往往是因为样本量太小（如16笔）且恰好处于有利行情中。判断策略真实优劣的金标准是全历史（如8年/116笔）的统计期望。必须警惕‘高胜率陷阱’：如果单笔平均亏损 > 单笔平均盈利，那么除非胜率极高（通常需>70%），否则策略总体期望值为负。在汇报策略效果时，应明确区分‘局部时段表现’与‘长期统计规律’，避免用户被短期红利误导。
