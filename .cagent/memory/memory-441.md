分时量比副图的口径：量比 = 累计量 ÷（5 日均量 × 已开盘时间占比）。实测某票 242 点、09:30 首值 0.87、09:35 峰值 3.41、15:00 收 0.70，全天集中在 0.7-1.0，属于真实形态不必怀疑数据错误。量比轴的基线应做自适应，否则曲线会一直贴底。量比 1.0 画虚线作参照。
