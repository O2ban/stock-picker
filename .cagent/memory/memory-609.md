将自然语言交易规则代码化时的最佳实践：1. **模糊词量化**：“接近”统一定义为固定比例容差（如0.2%），防止触发不稳定；2. **触发时点明确**：区分“盘中触及即触发”与“收盘确认触发”，前者更保守但避免盘中反复横跳导致的止损，后者滞后；3. **全成本估算**：做T策略利润薄，必须将佣金、印花税、滑点合并为单边固定损耗（如0.13%）作为盈亏平衡点，否则策略可能在实盘中因手续费而亏损。这些参数应在回测脚本中作为可配置常量暴露，便于敏感性分析。
