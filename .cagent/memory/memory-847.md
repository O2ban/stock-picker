用户对回测结果的解读要求是看结构而不只看总数：要求按卖出路径分档（冲到+1%即时卖、开盘即超1%按开盘卖、没冲到扛到收盘、被过滤没买），每档给出笔数/平均/中位数/胜率/累计。本例发现『所有盈利来自冲到即走的38笔（一分没亏），全部亏损集中在没冲到硬扛到收盘的13笔（-2.66%）』，这种拆解才能定位策略真正的窟窿，也便于用户拍板下一步改哪。
