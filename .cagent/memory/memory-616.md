当用户提出‘把A页的图表用到B页’的需求时，其隐含约束是：B页必须拥有与A页完全一致的交互体验（包括所有手势响应、副图联动、图例行为）。因此，实施路径不应是在B页重新实现或局部修补，而是直接引入A页的完整图表组件。用户反感‘做一半’的实现，认为那会导致体验割裂。
