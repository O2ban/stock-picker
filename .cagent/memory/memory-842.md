为看盘界面新增 301557 的逐日复盘视图，采用「数据准备先做：把分时分钟价整理成前端可直接使用的静态数据文件，前端只读、不做计算」的方式。数据规模为 101 个交易日 × 240 根分钟价、100 笔交易，且每天的分钟价与证据页的 paths 逐点一致。这样前端渲染的点位就等于证据数据，避免了前端二次计算出偏差。相关零散问题（15:00 那根的点标签被右边缘裁掉、卖点标签需要带「卖价（收益）」完整显示）属于展示层修正，不影响数据口径。
