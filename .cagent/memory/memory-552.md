stock-picker 分时图十字线原先把横线限制在价格主图内。扩展到副图的做法：把坐标换算的两个函数改成通用写法，并新增判断「横线当前落在哪个面板」的函数；十字线核心逻辑据面板归属决定读数展示（成交量子图显示「量 N」、量比副图显示「量比 X.XX」）。实现要点：读数标签贴到副图底边时会溢出画布，需按画布边界裁剪；盘中每 3 秒刷新若纵轴范围变化，横线在副图可能被挤走，需在 tick 越界检查中一并处理。
