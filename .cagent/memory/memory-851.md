603931 回测中 120 个交易日有 5 天收盘封死涨停，按「收盘买」规则实际买不进，予以剔除后有效结算 114 笔；最后一天买入的一笔因区间结束无法卖出也不计入。这与已有「跌停板封死无法买入导致虚假盈利」的教训互为镜像：凡以收盘价/开盘价假设成交的回测，都必须先检查涨跌停封板情况，剔除不可成交样本并明确告知用户有效性口径。
