在『冲到+1%即卖』类策略中，卖出时点是盘中任意分钟，必须用分钟K线逐根扫描最高价去判断首次触及时刻，并按该分钟的价格卖出（开盘就超过则用开盘价）。直接用日线『当日最高价≥昨收×1.01』会把盘中任何时刻的冲高都当成可卖，等于偷看全天结果；而用收盘价判定又漏掉盘中冲高。正确做法：按分钟序列推进，遇到第一个满足条件的分时点即触发。
