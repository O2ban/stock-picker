在短线交易策略研究中，用户定义的“中间价”（昨日最高价与最低价之和除以2）是一个关键的统计锚点。数据显示，今日最高价高于昨日中间价的概率稳定在79%左右，这意味着昨日中间价下方买入、博弈次日回收到该价位的策略具有统计正期望的基础（需扣除交易成本和不可执行样本）。该概念可作为后续策略优化的核心参照线。
