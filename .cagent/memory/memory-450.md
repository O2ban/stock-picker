分时图图例排布的三个要点：1) 价格图那一行放全部公式线（中、PP、HH、M20）并与价格曲线同屏可比，量比单独一行，公式线漏放或串到量比行都是 bug；2) 图例项从 3 增到 7 后窄屏会折成两行，而网格顶部原本只预留一行高度，折出的第二行会压住价格曲线顶部，需把预留高度改为按 panel 分别设置（如两行占 0-24px、预留 30px）；3) 图例里若再放『涨跌 +1.63%』会与顶部行情条重复并挤占宽度把 M20 挤到第二行，应删掉重复项。图例重排后务必截图目视确认没有压住曲线。
