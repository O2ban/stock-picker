腾讯分时接口每分钟只返回分钟末成交价，没有单分钟最高/最低。当前分时归档格式（时间+分钟末价+量）因此装不下分钟内OHLC。后果：归档聚合成的高低价与日K存在差异（本轮验证：北交所修复后剩余差异只有 high/low，112/94只），影响「距当日最低不超X个点」类回测规则，结果略偏保守。

「回看历史1分钟OHLC」主线绕不开的一步是把归档格式升级为能存四价（开高低收）。该改动会牵动分时图渲染、买点判定、回测结算等多个消费端。决策倾向：等数据源（free-stockdb / 付费lc1 / 其他）确定后一起做，避免改两遍。

注意与通达信1分钟线(.lc1)的差异：lc1每条32字节明确存单分钟开高低收四价+成交额量，是能补上单分钟高低价的候选源（见 memory-856）。
