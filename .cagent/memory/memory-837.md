高昨比百日均值门槛 >2% 看似严格，实测全市场 5517 只中有足够历史的票均值 2.25、中位数 2.13，一半以上天生就在 2 以上，>2% 通过 3140 只（57%），几乎等于没筛选。各档通过数：>1.5% 4539（82%）、>2.5% 1853（34%）、>3% 980（18%）、>3.5% 441（8%）、>4% 167（3%）、>4.5% 53（1%）。结论：这类指标更适合作为票池的「波动活跃过滤层」与其他策略叠加，门槛应放到 >3.5% 或 >4% 才有实际筛选意义。另发现选股引擎当时没有「按条件数值排序」能力，结果只按代码顺序截前 500 只，并非指标最高的 500 只。
