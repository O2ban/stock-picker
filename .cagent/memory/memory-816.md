用户对分时策略口径的校对要点：(1) 取消「必须先跌到水下再涨回来」；(2) 不限定「爬回来」阶段的量能结构，量能要求只作用于买点附近形态；(3) 突破判断的参照是「买点之前的最高点」而非另找一个「启动时刻」；(4) 买点必须在水上，即买点价格高于昨收，不只是站在分时中线之上；(5) 买点涨幅不超过2%是硬上限；(6) 形态反转需在买点处复查，不只在此前形态锚点检查一次。用户同时指出「买点不超2%，前期不可能超2%」说明第10条表述有误，需回代码核对实际实现。
