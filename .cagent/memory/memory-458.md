用户误以为『数据源1分钟才更新一次』，实际上游行情是秒级的，卡住的是我们自己加的两道闸：①服务端约5秒缓存（前端重复问价直接回旧答案，导致所谓3秒刷新实际最快5秒才真变一次）；②前端自己的问价节奏（分时3秒、列表60秒）。分时曲线走另一条分钟级数据通道（缓存约2秒），所以比分时顶部的报价更『活』，两条通道正是『价格对不上、不统一』的根源。要把看盘做到真正跟手，必须把服务端缓存降到约2秒左右、并让看盘这一只的价格请求绕过该缓存；只改前端节奏是打折的。另外用户明确要求：新价格没到之前必须显示上一次获取到的价格，不能直接缺一根最新K线。
