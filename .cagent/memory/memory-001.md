用户选股应用的核心设计出发点：同时支持日线、周线、月线级别分析，而非多数炒股app只支持日线或周线的单一模式。设计方案中日线、周线一期支持，月线预留周期抽象扩展。所有周期的量价指标统一在服务端预计算后写入数据库，前端只做展示，不在浏览器逐只请求全市场数据。
