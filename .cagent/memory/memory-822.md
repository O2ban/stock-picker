用户问「某只票为什么没进清单」时，正确做法是两件事并行：一是确认扫描程序本轮健康（每分钟一轮、每轮覆盖五千三百多只、全部正常返回，当天全市场 0 只符合也是正常结果），二是把该票分时数据单独取出按规则逐条过一遍指出卡点。这样能直接消解用户「是不是程序漏了」的疑虑，避免只答个票、留下程序是否可靠的悬念。
