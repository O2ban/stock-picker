本机归档的分钟数据只覆盖最近几个交易日，腾讯接口只能回溯近5日、无法回补更早日期。新浪1分钟接口对目标日（如2026-11-12）能拿到单票约238根（9:30首根空档不计入，覆盖9:32-15:00，对9:35起算窗口足够），但只滚动保留约8-9个交易日，不是长期历史库。Baostock/东财5分钟数据不能冒充1分钟策略验证。可长期用的替代方案是每日收盘后定时归档当天1分钟数据（但磁盘紧张只能存当天被选中的票，漏一天即永久丢失）。缺全市场分时数据时不得用日线推算买点、不得上报虚构的出票数或胜率。
