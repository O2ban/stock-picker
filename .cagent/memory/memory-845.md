除权复牌日（如前一天114.9、当天开81.42）会造成价格断层。若均线用原始价计算，跨除权的MA窗口会混入除权前高价，数值被高估（本例MA20从86.78被算成88.45），使『跌破MA5与MA20不买』的过滤产生误判。判断方法：用复权序列算均线，并逐票核对跨除权的首笔买入日。除权日之后原始价与前复权价相等，因此只有跨除权的那几笔受影响，但必须修正。
