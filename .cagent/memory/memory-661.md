stock-picker 日内策略待用户决定的事项：(1) 缩量门槛——严档筛出 111 只、放宽 184 只、收紧 72 只，用户希望每天大概选多少只；(2) 出手时间窗口——「十点左右」就停，还是放宽到「十点一刻以前」；(3) 「价格必须站在那条下降的中间线上方」是硬性条件还是加分项；(4) 复盘页手续费率（0.13%）与主策略（0.26%）不一致，是否统一。这类待拍板事项应整理成带建议的少量问题交给用户。
