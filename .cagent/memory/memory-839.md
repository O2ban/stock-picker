100 笔中的 38 笔「没摸到 +1% → 收盘卖」的样本，当天最高涨幅平均只有 -0.08%、中位 +0.12%，最差个案当天最高只到 -0.01%、最终 -10.09%。共同点是开盘就趴着、一整天没起来、越等越低、最后砸在最低区间收盘。反过来，摸到的那 62 笔有一半在开盘十分钟内就撤退、平均 +1.01%，说明「拐头就跑」这个动作本身有效，只是挡不住「根本没起来」的日子。做此类策略诊断时应把样本按「是否触发止盈」拆开分别统计，而不是只看总平均。
