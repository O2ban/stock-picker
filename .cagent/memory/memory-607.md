在加入“大盘连跌3天以上”、“站上20日均线”、“跌到中间价下方”三个严格条件后，近5年内仅有109个交易日满足条件（平均每年约22天）。虽然该组合的最大回撤控制在-10.8%以内，但累计收益仅15.4%，年化约3%，扣除交易成本后吸引力有限。这表明在追求高确定性时，过度堆叠过滤条件会导致机会成本过高，甚至不如直接持币。
