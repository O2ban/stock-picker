stock-picker 分时图左右滑动换股时，顶部行情条会出现明显「晚加载」式的布局跳动。根因：行情条不在滑动的两层画布内，而是一条固定不动、两套画布共用的条；换股瞬间画布已滑走，行情条仍停在上一只股票的数字上，等网络数据返回后才替换，数字位数不同导致整块区域重排一次。日K图因走了本地缓存，几十毫秒内就衔接上，所以无感。修法：滑动时邻票分时数据其实已预渲染到手（预览层就是用它画的），直接用这份数据先填行情条，网络数据回来后再静默替换为最新值。排查此类「晚加载」问题应先判断是网络耗时还是换股瞬间沿用了旧数据造成的重排。
