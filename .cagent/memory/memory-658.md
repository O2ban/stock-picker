stock-picker 分时图原先只能取当天分时，若买点清单显示的是历史某日（如 11 月 18 日），曲线上没有那段时间，买点三角无法绘制。修复要点：前端三处入口（点开、横滑换股、邻票滑入预览）都把「买点那天的日期」带给后端，后端支持按指定日期取历史分时，让买点与曲线用同一天的数据。另有一处造标记时调用了不存在的工具函数导致整图报错，需一并修掉。
