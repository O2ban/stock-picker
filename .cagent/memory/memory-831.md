stock-picker 全市场一分钟下载按实测速度约需 37 分钟，远超单条命令两分钟的工具时限，因此必须小批量（约 100 只）执行，每条执行内完成下载+筛选+盘点并报告真实结果；已达时限时已落盘数据保留，后续靠断点续传接着跑。同时注意下载地址只保留约 8–9 个交易日，失败的票要尽快重试，否则数据窗口滑走就永久缺失。磁盘方面需每批核对余量（实测剩余约 5.6GB）。
