回测显示，“大盘连跌”状态是短线策略的生存边界：当大盘未处于连跌状态时，策略平均每笔亏损0.28%；当大盘连跌1-4天时，策略转为盈利（平均+0.11%至+0.27%）。然而，连跌天数超过5天后，由于样本减少且市场进入非线性状态，规律性失效，不可将其作为精确的择时刻度。因此，策略必须严格限制在“大盘处于短期下跌/恐慌”的环境中使用。
