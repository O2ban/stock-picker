自动化探针里判断『周期按钮是否点中分时』不能靠按钮文本精确相等：该按钮组抓出的文本是『分时日线周线』整段拼接，`t==='分时'` 永远为假，导致点击从未生效，几轮所谓的『分时换股』测试实际全在日K上跑，结论适用范围失效。正确做法是按按钮属性/选择器直接点，并在点击后回读当前周期确认真的切过去了，再采信本轮数据。凡是靠点击 UI 控件驱动的验证脚本，都必须加一步『操作后回读状态』的自检，否则静默走错分支的假数据会让整组结论作废（这也意味着此前『已多视口验证』的可信度要打折）。
