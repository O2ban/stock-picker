当前选股每次都会从头算一遍，不记住「这套策略、这个日期我刚算过、名单一样」。对于同策略同一天的重复查询，可直接返回上次名单，无需读盘和重算。在3.7G内存、4G+资料库装不下的机器上，这比继续优化预筛更直接；若要治本，也可将预筛所需的短窗数据单独存成一份按股票排序的小表让硬盘顺序读，但数据结构改动更大。缓存方案后端改动小，可快速落地。
